# Ally

**Ally: An AI-Powered Intelligent Companion and Safety Monitoring System** — a Final Year Project at Universiti Sains Malaysia (CAT405).

Ally is an Android phone placed facing an older adult who lives alone. All AI runs on the phone: it detects falls, reads facial expressions (with consent), recognises objects around the person, and talks with them as a companion. When something is wrong, it calls and notifies a guardian.
